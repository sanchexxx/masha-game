# Выгрузка для coding-агента
## Проект: браузерный MVP игры «Прятки с Безликом»
### Версия задачи: Stage 1 — первые персонажи, базовая 3D-сцена, управление, физика, раунд, призрак

---

## 1. Цель этапа

Нужно собрать **первый рабочий 3D-прототип**, который можно открыть на **ПК и телефоне** в браузере.

Главная задача этого этапа:

1. **Воссоздать первых персонажей по приложенным картинкам** максимально близко по образу, цветам, силуэту и деталям.
2. Сделать **управление и физику передвижения в духе Roblox**:
   - понятное перемещение;
   - прыжок;
   - бег;
   - коллизии;
   - ощущение «персонаж бегает как в Roblox».
3. Сделать **игровой цикл одного раунда**:
   - игрок появляется на карте;
   - можно перемещаться;
   - после запуска сценария появляется **призрак / Безлик**;
   - призрак выбегает и начинает преследование;
   - базовая игровая логика уже работает.
4. Подготовить фундамент для следующих этапов, но **не делать сейчас всё подряд**.

---

## 2. Что делаем СЕЙЧАС

### 2.1. Персонажи
На этом этапе нужно:

- взять **первые ключевые персонажи** из приложенных изображений;
- отрисовать / собрать их в 3D;
- сохранить **максимальную визуальную близость** к картинкам;
- сделать персонажей стилизованными, качественными, выразительными;
- персонажи должны выглядеть как **игровые 3D-герои**, а не как случайные болванки.

### Обязательные требования к персонажам:
- silhouette readability — персонаж узнаётся по силуэту;
- узнаваемые цвета, аксессуары и пропорции;
- аккуратные материалы;
- нормальная геометрия для реального движения;
- единый стиль всей линейки героев;
- оптимизация под браузер.

### Минимальный набор для Stage 1:
1. **Главный игровой персонаж (девочка / Маша-аватар)**  
2. **Безлик / призрак**  
3. **1–2 дополнительных персонажа** из первых карточек

Если времени хватает — можно сразу собрать больше, но минимум: **главный герой + Безлик + ещё 1–2**.

---

## 3. Что НЕ делаем сейчас

Это **не входит в текущий этап**:

- полноценный редактор аватара;
- система «создай своего персонажа»;
- магазин с полной экономикой;
- финальные улучшения до 3 фаз;
- кастомизация одежды;
- весь большой лобби-флоу;
- мультиплеер;
- чат;
- полноценные раунды с большим количеством правил;
- прокачка после каждого раунда;
- сложная система монет / прогрессии;
- много карт.

Это всё будет потом.

---

## 4. Игровой режим на этом этапе

Нужен **один базовый игровой сценарий**:

### Сценарий MVP
1. Игрок заходит в прототип.
2. Выбирает / получает стартового персонажа.
3. Загружается 3D-карта.
4. Игрок может:
   - ходить;
   - бегать;
   - прыгать;
   - вращать камеру;
   - обходить препятствия.
5. Через событие / триггер / короткую задержку появляется **Безлик / призрак**.
6. Призрак начинает преследовать игрока.
7. Игрок может убегать и проверять механику передвижения.
8. Если призрак догнал — срабатывает состояние проигрыша.
9. Если игрок продержался нужное время — срабатывает состояние завершения раунда.

---

## 5. Камера и управление

### Режим камеры
Нужен **вид от третьего лица**, максимально удобный и «по-игровому» читаемый.

Дополнительно:
- архитектуру сделать так, чтобы потом можно было легко добавить **вид от первого лица**;
- но на этом этапе основной фокус — **третье лицо** и ощущение Roblox-like movement.

### ПК-управление
- **WASD** — движение
- **Space** — прыжок
- **Shift** — бег / спринт
- **мышь** — вращение камеры
- камера плавная, не дёрганая

### Мобильное управление
- левый виртуальный стик — движение
- правая зона / свайп — обзор
- кнопка прыжка
- кнопка бега (если нужно)
- всё должно быть играбельно на телефоне

---

## 6. Физика и ощущения движения

Нужно сделать **ощущение управления похожим на Roblox**:

### Обязательно:
- capsule / character controller;
- устойчивое движение по плоскости;
- нормальные коллизии со стенами и объектами;
- прыжок с адекватной дугой;
- гравитация;
- персонаж не должен застревать в геометрии;
- скорость ходьбы и бега настраиваемая через config;
- плавный разворот персонажа в сторону движения;
- базовая анимация idle / walk / run / jump.

### Важно:
Нужно не просто «технически двигается», а чтобы по ощущениям это было:
- отзывчиво;
- приятно;
- по-игровому;
- с читаемой инерцией, но без ватности.

---

## 7. Призрак / Безлик

### На этом этапе нужно:
- реализовать появление Безлика;
- Безлик должен быть полноценным 3D-персонажем;
- он должен уметь:
  - появляться / спавниться;
  - двигаться по карте;
  - преследовать игрока;
  - догонять игрока;
  - вызывать проигрыш / захват.

### Для Stage 1 достаточно:
- простой AI pursuit;
- pathfinding можно сделать базовый или упрощённый;
- если сложный navmesh не успевает, допускается простое преследование + обход простых препятствий;
- важно, чтобы это уже **работало как геймплей**, а не просто стоящий NPC.

### Дополнительно приветствуется:
- эффект появления;
- немного «жуткая», но не слишком страшная подача;
- атмосферный звук / визуальный эффект.

---

## 8. Карта

Нужна **одна компактная карта** для теста.

### Требования к карте:
- атмосферная;
- читаемая;
- с препятствиями;
- с местами, где можно маневрировать и убегать;
- не перегруженная;
- красиво выглядит и на ПК, и на телефоне.

### На карте должны быть:
- дорожки / открытое пространство;
- несколько объектов / домиков / укрытий;
- освещение;
- понятные границы уровня;
- зона появления игрока;
- зона появления Безлика.

---

## 9. Графика и качество

Нужно сохранить **максимально высокий визуальный уровень для прототипа**.

### Что ожидается:
- аккуратные материалы;
- красивые цвета;
- выразительные формы;
- мягкий свет / хороший light setup;
- тени;
- общее ощущение качественной детской атмосферной игры.

### Приоритет:
не фото-реализм, а **качественный stylized 3D**.

### Важно:
Нельзя жертвовать производительностью полностью ради картинки.
Нужно найти баланс:
- красиво;
- читаемо;
- стабильно работает в браузере.

---

## 10. Технический стек (рекомендуемый)

Предпочтительно:

- **Three.js** или **Babylon.js** для браузерного 3D
- JavaScript / TypeScript
- modular architecture
- персонажи в формате **glb / gltf**
- текстуры оптимизированные
- mobile-friendly rendering

Если агенту удобнее другой стек для веб-прототипа — допустимо, но результат должен запускаться по ссылке в браузере.

---

## 11. Архитектурные требования

Проект должен быть разбит логически:

- `assets/characters`
- `assets/environment`
- `src/player`
- `src/enemies`
- `src/world`
- `src/ui`
- `src/game`
- `src/config`

### Обязательно вынести в конфиг:
- скорость ходьбы;
- скорость бега;
- высоту прыжка;
- гравитацию;
- радиус захвата призрака;
- время до появления призрака;
- длительность тестового раунда.

---

## 12. Что должно быть готово в результате

### Итог Stage 1:
Должен быть рабочий билд, где:

1. Открывается игра по ссылке в браузере.
2. Есть стартовая сцена / простой вход.
3. Есть 3D-персонаж игрока.
4. Есть 3D-Безлик.
5. Есть базовая карта.
6. Есть управление на ПК.
7. Есть управление на телефоне.
8. Есть физика передвижения.
9. Есть прыжок, бег, камера.
10. Есть запуск раунда.
11. Есть появление призрака.
12. Есть преследование игрока.
13. Есть проигрыш при поимке.
14. Есть завершение тестового раунда по времени.
15. Всё выглядит достаточно качественно, чтобы показывать как пилот.

---

## 13. Критерии приёмки

Работа считается принятой, если:

- визуально персонажи похожи на референсы;
- движение ощущается как игровое, а не сырое;
- персонаж нормально управляется на ПК и телефоне;
- призрак реально преследует игрока;
- сцена не разваливается по производительности;
- прототип можно показать как серьёзную основу будущей игры.

---

## 16. Короткий prompt для coding-агента

Собери первый браузерный 3D-прототип игры «Прятки с Безликом». Возьми приложенные изображения как главные референсы персонажей и максимально близко воссоздай первых героев в stylized 3D. На текущем этапе сделай: главного игрового персонажа, Безлика и ещё 1–2 персонажа; одну атмосферную карту; третье лицо; управление и физику перемещения в духе Roblox (ходьба, бег, прыжок, коллизии, камера); запуск раунда; появление призрака; преследование игрока; проигрыш при поимке; завершение раунда по времени; работу на ПК и телефоне. Не делай пока полноценный редактор аватара, мультиплеер, магазин, чат и большие системы прогрессии — только крепкий качественный Stage 1 с рабочим геймплеем и красивой подачей.

---

## 17. Важное уточнение для агента

Картинки с персонажами будут приложены отдельно.  
Их нужно считать **главным визуальным источником правды**.

Если что-то неочевидно:
- сохранить силуэт;
- сохранить цветовую схему;
- сохранить ключевые аксессуары;
- сохранить общий характер персонажа.

Главная задача:  
**не просто сделать прототип, а сделать основу, в которой уже чувствуется будущая качественная игра.**
