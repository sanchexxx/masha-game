# Передача облачному агенту: красивый дождь (03.11.2026)

**Зачем:** у Тоторо новое умение «Вызов дождя» (клавиша 3): дождь на всю карту 10 секунд, все промокают,
мокрые Безлики медленнее и летают низко. Игровая часть уже сделана. Сейчас дождь нарисован просто —
косые линии вокруг камеры (`src/fx/rain.js`). **Твоя задача — сделать его красивым**, «как в мультике
Ghibli». Встраивает агент на Маке. Общие правила — `HANDOFF-CLOUD-2026-11.md` §0.

## Что должно быть видно
1. Ливень: тонкие светлые струи с лёгким наклоном, разной длины и яркости, мягко появляется и стихает (~1 с).
2. Брызги и круги на земле и в лужах вокруг игрока; на воде (Лес духов) — рябь.
3. Небо и туман чуть темнее и холоднее на время дождя, потом плавно обратно.
4. Капли на «стекле» камеры — несколько стекающих капель поверх экрана (можно HTML/CSS-слоем).
5. **Мокрые персонажи:** функция, которая делает модель темнее и чуть блестящей (влажной), и обратно.

## Формат — СТРОГО (под это уже написана игра)
Заменить файл **`src/fx/rain.js`** целиком, сохранив набор команд:
```js
export function createRain(scene) → {
  active,            // true, пока идёт дождь
  setScene(scene),   // игра сменила карту — перенести дождь в новую сцену
  start(seconds),    // начать (повторный вызов продлевает)
  stop(),            // сразу убрать (конец раунда, выход в меню)
  update(dt, camera) // каждый кадр
}
export function wetLook(root, k)   // НОВОЕ: k=0 сухой … 1 мокрый; без порчи общих материалов (клонировать на меш)
```
- Только `three` (без постобработки и сторонних библиотек), должно работать и на three r186, и на r160
  (старые iPhone, WebGL1).
- Не трогать `scene.fog`/`scene.background` навсегда — запомнить и вернуть после дождя.
- Бюджет: на iPhone 12 не больше ~2–3 мс на кадр; частиц — до ~4000.
- Можно добавить текстуры в `assets/fx/rain/` (PNG/JPEG, до 512 px).
