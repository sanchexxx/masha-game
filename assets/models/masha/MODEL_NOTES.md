# Маша — 3D-модель (04.11.2026)

**Как сделано:** по развороту `refs/masha-sheet.jpg`, рост **1,34 м**, как просил владелец.
- Модель собрана скриптом в Blender, как Тоторо, Безлик и Моти.
- Стиль мультяшный, а не фото: так ей лучше стоять рядом с остальными героями игры.
- **Потрачено 0 ₽.**

**Как собрать заново:** `cd _build && python3 mpaint.py && python3 mbuild.py`.

## Файл `masha.glb`
- **Размер:** 9 000 треугольников, 1 МБ.
- **Оси:** метры, Y вверх, смотрит на +Z, (0, 0, 0) между ступнями. Рост 1,34 м до макушки.
- **Кости:**
  - `Hips, Spine, Chest, Head`;
  - `Braid1..3` — коса, качается во всех движениях;
  - `LeftArm, LeftForeArm, LeftHand`, то же справа;
  - `LeftUpLeg, LeftLeg, LeftFoot`, то же справа.
- **Узлы:**
  - `Body` — голова, лицо, руки, ноги, туфли;
  - `Dress` — платье, воротник, пуговицы;
  - `Hair` — волосы, коса, резинки с помпонами, зелёные ленты;
  - `Spirits` — 3 огонька, включать по умениям.

## Лицо: атлас 2×2 (`_build/tex/face.png`)
Сдвиг: `faceMat.map.offset.set(0.5 * (n % 2), 0.5 * Math.floor(n / 2))`.

| n | Выражение |
|---|---|
| 0 | улыбка с зубками, без одного зуба, как на развороте |
| 1 | моргает |
| 2 | смеётся |
| 3 | удивление, рот «о» |

## Скины
Игра меняет `map` у материалов `Dress`, `Cuff`, `Collar`; текстуры лежат в `_build/tex/`, при смене ставить `flipY = false`.

| Скин | Что |
|---|---|
| `classic` | тёмно-синее школьное платье |
| `summer` | голубое платье |
| `forest` | зелёное платье в листиках |
| `holiday` | синее платье с белым кружевом у подола |

## Клипы (30 кадров в секунду)
- Общие: `Idle, Walk, Run, Jump, Fall, Land, Swim, Crouch, Wave`.
- Умения с разворота:
  - `Cast` — «Светлый круг», руками рисует круг;
  - `Spirit` — «Энергия духа»: ладони у груди, потом толчок вперёд;
  - `Summon` — «Связь с духами»: рука вверх;
  - `Braid` — «Сила кос»: кружится, коса хлещет.
- Зациклены: `Idle, Walk, Run, Fall, Swim, Crouch`.
