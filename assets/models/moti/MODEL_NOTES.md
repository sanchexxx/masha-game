# Дядюшка Моти — 3D-модель (04.11.2026)

**Как сделано:** по развороту `refs/moti-sheet.webp`, целиком скриптом в Blender, как Тоторо и Безлик. Платных сервисов не было, **потрачено 0 ₽**.

**Как собрать заново:** `cd _build && MAPTEX=<папка с текстурами карты> python3 mpaint.py && python3 mbuild.py`.
- Доски, черепица и листья рюкзака берутся из `assets/models/map/tex` (ветка `claude/masha-map-detail`).
- Готовые копии этих текстур уже лежат в `_build/tex/`.
- Скрипт использует общие помощники из `../../totoro/_build/`.

## Файл `moti.glb`
- **Размер:** 9 430 треугольников, 1,7 МБ. Без Draco и KTX2.
- **Оси:** метры, Y вверх, смотрит на +Z, (0, 0, 0) между ступнями. Рост 2,4 м вместе со шляпой.
- **Кости:**
  - `Hips, Spine, Chest, Head`;
  - `LeftArm, LeftForeArm, LeftHand`, то же справа;
  - `LeftUpLeg, LeftFoot`, то же справа.
- **Узлы:**
  - `Body` — тело, лапы, ноги, усы-щёки;
  - `Fur` — пряди меха, прозрачность по маске;
  - `Face` — лицо, прозрачность по маске;
  - `Loincloth` — повязка;
  - `Hat` — шляпа, на кости `Head`;
  - `Backpack` — домик-рюкзак на кости `Chest`;
  - `Lantern` — посох с фонарём-лапкой на кости `RightHand`;
  - `Spirits` — 2 огонька на кости `Hips`, игра может их крутить.

## Скины (`skins` в `_build/tex/`, одна развёртка)
Игра меняет `map` у материалов:

| Скин | Мех `Body` | Пряди `FurCard` | Шляпа `Hat` | Повязка `Cloth` |
|---|---|---|---|---|

| winter | `winter_fur.jpg` | `winter_card.png` | `winter_hat.jpg` | `winter_cloth.jpg` |

Цвета взяты из `MOTI_SKINS` в `src/characters/moti.js`. При смене текстуры ставить `flipY = false`.

## Лицо: атлас 2×2 (`face.png`)
Сдвиг: `faceMat.map.offset.set(0.5 * (n % 2), 0.5 * Math.floor(n / 2))`.

| n | Выражение |
|---|---|
| 0 | обычное |
| 1 | моргает |
| 2 | смеётся с открытым ртом |
| 3 | радость, глаза-дуги |

## Клипы (30 кадров в секунду)
- Общие: `Idle, Walk, Run, Jump, Fall, Land, Swim, Crouch`.
- Действия: `Swing` (удар фонарём), `Cast`, `Summon`, `Wave`, `Path` (путь фонарей: рука с фонарём вперёд).
- Это ровно имена действий из `moti.js`: `swing / cast / summon / wave / path`.
- Зациклены: `Idle, Walk, Run, Swim, Fall, Crouch`.

## Сравнение с разворотом
См. `preview/compare.png`, `hero-shot.png`, `face.png`, `anims.png`.

| Что | Итог |
|---|---|
| Силуэт | Близко: груша-тело, короткие толстые ноги, большие лапы, шляпа с полями, рюкзак-домик выше головы |
| Мех | Кремовый, пряди по краям и на плечах. На развороте мех пушистее и объёмнее, особенно «борода» и щёки |
| Лицо | Маленькие глаза, нос, улыбка, усы по бокам, 4 выражения. Усы на развороте — одна пышная масса, у нас два помпона |
| Рюкзак | Деревянный домик: доски, крыша, полки, знамя с лапкой, фонарики, горшки. На развороте больше мелочей, лиан и цветов |
| Фонарь | Посох с фонарём-лапкой, светится |
| Огоньки-духи | Есть два, но без мордочек, как на развороте |

**Честная оценка: 7/10.**

До 10 не хватает:
- объёмного пушистого меха, как на развороте (нужен генератор 3D или художник);
- мордочек у огоньков;
- мелочей на рюкзаке.
